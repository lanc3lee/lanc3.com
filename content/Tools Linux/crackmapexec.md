**CrackMapExec (CME)** is officially no longer being maintained by its original creator. It has been replaced by **NetExec (NXC)**

- The original CME repository became a "read-only" archive. A new community-driven team forked it, cleaned up the code, and rebranded it as **NetExec** to keep it updated with modern Windows security changes.
    
- **The Commands:** Almost everything is identical. If you knew a CME command, you just swap `cme` for `nxc`
